# Барахолка (план / следующий PR)

## Смысл
Продаётся всякий шмот с шансом выцепить полезное; не бесконечные стоки.

## Продажа игроку
- Автоподбор сервером (излишки / дроп) + лоты игроков за вчера
- Конечные остатки (могут кончиться)
- Вверху — предметы дня с надбавкой (востребованные)

## Скупка у игрока
- До 10 стаков
- Только недорогие предметы (лимит цены из config)

## Реализация (отдельный PR)
1. FleaMarketManager + таблицы stock / daily_demand
2. GUI 54 gui-gen-5: вкладки Продажа / Скупка
3. Job: ночной ролл спроса + пополнение стока
4. Без префикса LoveShops в сообщениях
