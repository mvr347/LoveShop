# LoveShops — Flow диаграммы основных сценариев

## Сценарий 1: Продажа предмета скупщику

```
┌─────────────────────────────────────────────────────────────────┐
│ Игрок кликает на предмет в Buyer GUI                            │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ InventoryClickListener → InventoryClickEvent                     │
│ - Определить тип GUI (title = "Скупщик")                         │
│ - Извлечь ItemStack из слота                                    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ BuyerManager.canPlayerSell(player)                               │
│ - Проверить override статус в БД                                │
│   - Если bad/aggressive: → REJECT_PLAYER (ветка ниже)           │
│   - Если default/good: → continue                               │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                              YES
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ PriceCalculator.calculateBuyPrice(player, itemStack)             │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ basePrice = config.prices.get(item.getType())               │ │
│ │ variance = random(-30%, +30%)                               │ │
│ │ penalty = getPenaltyPercent(player, item)                   │ │
│ │ reputation = getLoveBehaviorAPI().getReputation(player)     │ │
│ │ bonus = reputation.isGood() ? +20% : 0%                     │ │
│ │                                                              │ │
│ │ FINAL_PRICE = basePrice × variance × (1-penalty/100)        │ │
│ │              × (1 + bonus/100)                              │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ BuyerManager.buyItem(player, itemStack, finalPrice)              │
│ [Async task via AsyncScheduler]                                 │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ 1. Вставить запись в buyer_inventory:                       │ │
│ │    INSERT (npc_id, player_uuid, item_data, base_price,      │ │
│ │            quantity, received_at)                           │ │
│ │                                                              │ │
│ │ 2. Обновить penalty в buyer_prices_history:                 │ │
│ │    UPDATE submit_count = submit_count + 1                   │ │
│ │    UPDATE price_penalty_percent += 5%                       │ │
│ │                                                              │ │
│ │ 3. Back to main thread:                                      │ │
│ │    - Вычесть itemStack из inventory                         │ │
│ │    - Добавить currency (ItemsAdder/ExecutableItems)         │ │
│ │    - Отправить сообщение:                                   │ │
│ │      "§aСкупщик: Отличный товар! Вот тебе §b{price}§a!"    │ │
│ │    - Показать зелёную голову в GUI                          │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                          SUCCESS
                              ↓
                    [Предмет убран, валюта выдана]
                    [GUI обновлён для игрока]
                    [Сообщение отправлено]


═════════════════════════════════════════════════════════════════

ВЕТКА: REJECT_PLAYER (если статус bad/aggressive)
┌─────────────────────────────────────────────────────────────────┐
│ BuyerManager.rejectPlayer(player, status)                        │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ if status == "bad":                                          │ │
│ │   message = getRandomMessage(config.messages.reject-bad)     │ │
│ │ else if status == "aggressive":                              │ │
│ │   message = getRandomMessage(config.messages.reject-agg)     │ │
│ │                                                              │ │
│ │ player.sendMessage(message)                                  │ │
│ │ showBlackSkullHead(GUI, slot)                                │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                          REJECTED
                              ↓
                    [Сообщение отправлено]
                    [Предмет остаётся в инвентаре]
                    [Чёрная голова показана]
```

## Сценарий 2: Торговец приходит в воскресенье (Schedule)

```
┌─────────────────────────────────────────────────────────────────┐
│ Каждый день в 10:00 (воскресенье):                               │
│ GlobalRegionScheduler запускает проверку                         │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ SellerManager.spawnSeller() [Async]                              │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ 1. Проверить день недели:                                   │ │
│ │    if (today != SUNDAY) return                              │ │
│ │                                                              │ │
│ │ 2. Запрос в БД:                                              │ │
│ │    SELECT COUNT(*) FROM buyer_inventory WHERE sold_at IS NULL │
│ │                                                              │ │
│ │ 3. Проверка минимума:                                        │ │
│ │    if (count < 10) {                                         │ │
│ │      sendMessage("Торговцу не интересно приходить")          │ │
│ │      return                                                  │ │
│ │    }                                                         │ │
│ │                                                              │ │
│ │ 4. Back to main thread:                                      │ │
│ │    - Получить координаты NPC тип="seller" из БД             │ │
│ │    - Спавнить entity (ArmorStand + Item with skin)          │ │
│ │    - Отправить broadcast сообщение:                          │ │
│ │      "§e[Барахолка] §fТорговец приехал!..."                 │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                          SPAWNED
                              ↓
        [NPC видим в мире, может быть кликнут]
        [Игрок может открыть Seller GUI]


═════════════════════════════════════════════════════════════════

В 18:00 (воскресенье):
┌─────────────────────────────────────────────────────────────────┐
│ SellerManager.despawnSeller() [Async]                            │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ 1. Найти entity торговца в мире                             │ │
│ │ 2. Удалить entity (remove())                                │ │
│ │ 3. Отправить broadcast:                                     │ │
│ │    "§e[Барахолка] §fТорговец уезжает!..."                   │ │
│ │ 4. Закрыть GUI у всех, кто его открыл                       │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                          DESPAWNED
                              ↓
            [NPC исчезает из мира]
            [GUI закрывается для игроков]
```

## Сценарий 3: Игрок покупает на барахолке (Race Condition Protection)

```
┌─────────────────────────────────────────────────────────────────┐
│ Игрок А кликает на товар в Seller GUI                           │
│ Одновременно Игрок Б кликает на ТОЖ же товар                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓
           ┌──────────────────────┬──────────────────────┐
           ↓                      ↓                      ↓
   [Игрок А клик]       [Игрок Б клик]        [Проверка в БД]
           ↓                      ↓                      
   ┌─────────────┐      ┌─────────────┐     
   │Transaction A│      │Transaction B│     
   │ в SQLite    │      │ в SQLite    │     
   └─────────────┘      └─────────────┘     
           ↓                      ↓              
    Обновить:             Обновить:         
    sold_at NOW      ✓    sold_at NOW      ✗
    (SUCCESS)               (Constraint!)      
           ↓                      ↓              
   SellerManager          ERROR:               
   .broadcastGuiUpdate()   UNIQUE KEY          
           ↓               VIOLATION           
    Отправить update       ↓                   
    на ВСЕ активные    SellerManager          
    Seller GUI:          .rejectPurchase()    
    - Удалить item       ↓                    
    - Показать:       Отправить:             
      RED SKULL      "Товар уже куплен"      
    - Broadcast         RED SKULL             
      сообщение        в GUI                  
                           ↓
   ┌──────────────┐   ┌──────────────────┐
   │  A успешно   │   │  B отклонён      │
   │  куплен      │   │  race condition  │
   │  товар       │   │  protection ✓    │
   └──────────────┘   └──────────────────┘
```

**Ключ:** При покупке А:
1. SQL `UPDATE buyer_inventory SET sold_at = NOW() WHERE id = X`
2. B пытается обновить ТОТЖЕ ROW → CONSTRAINT VIOLATION
3. Catch ошибку в Java
4. Back to main thread → GuiUpdater.broadcastGuiUpdate()
5. Все открытые GUI обновляются: проданный товар → RED SKULL

## Сценарий 4: Аукцион редких предметов (24 часа)

```
ВОСКРЕСЕНЬЕ 10:00:
┌─────────────────────────────────────────────────────────────────┐
│ Аукционер спавнится, на нём "редкие товары"                     │
│ Фиксированный список лотов (из конфига или добавлено вручную)    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ AuctionManager.createAuction(itemStack, startingPrice)           │
│ [Async]                                                          │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ INSERT INTO auctions:                                        │ │
│ │   auctioneer_npc_id, item_data, starting_price              │ │
│ │   starts_at = NOW(), ends_at = NOW() + 24 HOURS             │ │
│ │   status = 'active', current_highest_bid = 0                │ │
│ │ RETURN auction_id                                            │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              ↓
        [Аукцион активен, игроки видят его в GUI]


ИГРОК СТАВИТ СТАВКУ:
┌─────────────────────────────────────────────────────────────────┐
│ AuctionManager.placeBid(player, auctionId, bidAmount) [Async]    │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ 1. Проверка валидности ставки:                               │ │
│ │    - bidAmount > currentHighestBid?                           │ │
│ │    - Минимальный шаг соблюдён?                               │ │
│ │      if percentage: step = currentBid × 5%                   │ │
│ │      if fixed: step = 50                                     │ │
│ │                                                              │ │
│ │ 2. Проверка средств:                                         │ │
│ │    currentBalance = getCurrencyBalance(player)               │ │
│ │    if (bidAmount > currentBalance) {                         │ │
│ │      return ERROR "Недостаточно монет"                       │ │
│ │    }                                                         │ │
│ │                                                              │ │
│ │ 3. Зарезервировать валюту:                                   │ │
│ │    - Вычесть из инвентаря: removeCurrency(bidAmount)         │ │
│ │    - Вставить в reserved_currency:                           │ │
│ │      (player_uuid, reserved_amount, last_bid_auction_id)    │ │
│ │                                                              │ │
│ │ 4. Записать ставку:                                          │ │
│ │    INSERT auction_bids (auction_id, bidder_uuid, bid_amount) │ │
│ │    UPDATE auctions SET current_highest_bid, highest_bidder   │ │
│ │                                                              │ │
│ │ 5. Вернуть предыдущему ставившему валюту (если был):         │ │
│ │    if (previous_bidder != NULL) {                            │ │
│ │      addCurrency(previous_bidder, previous_bid_amount)       │ │
│ │      UPDATE reserved_currency SET reserved = 0 WHERE player  │ │
│ │    }                                                         │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                        УСПЕШНО
                              ↓
    [Валюта зарезервирована, текущая ставка обновлена]
    [GUI обновлён для всех]
    [Сообщение: "Ставка принята: {bid_amount}"]


ОТМЕНА СТАВКИ:
┌─────────────────────────────────────────────────────────────────┐
│ AuctionManager.cancelBid(player, auctionId) [Async]              │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ 1. Проверить текущую наибольшую ставку:                      │ │
│ │    if (player != current_highest_bidder) {                   │ │
│ │      return ERROR "Ты не лидер"                              │ │
│ │    }                                                         │ │
│ │                                                              │ │
│ │ 2. Вернуть валюту:                                            │ │
│ │    addCurrency(player, bid_amount)                           │ │
│ │    UPDATE reserved_currency SET reserved = 0                │ │
│ │                                                              │ │
│ │ 3. Удалить ставку из таблицы:                                │ │
│ │    DELETE FROM auction_bids WHERE auction_id AND bidder      │ │
│ │    UPDATE auctions SET current_highest_bid = 0               │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                        УСПЕШНО
                              ↓
    [Валюта вернута, ставка удалена]


ПОНЕДЕЛЬНИК 10:00 (аукцион заканчивается):
┌─────────────────────────────────────────────────────────────────┐
│ Scheduler проверяет: SELECT * FROM auctions WHERE ends_at < NOW │
│ Находит завершённые аукционы                                    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ AuctionManager.completeAuction(auctionId) [Async]                │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ 1. Получить информацию аукциона:                             │ │
│ │    SELECT * FROM auctions WHERE id = auctionId               │ │
│ │    SELECT * FROM auction_bids WHERE auction_id ORDER BY ...  │ │
│ │                                                              │ │
│ │ 2. Если нет ставок:                                          │ │
│ │    UPDATE auctions SET status = 'cancelled'                  │ │
│ │    return                                                    │ │
│ │                                                              │ │
│ │ 3. Выплатить продавцу (если это был лот):                    │
│ │    (можно добавить логику переводов денег если нужно)        │ │
│ │                                                              │ │
│ │ 4. Back to main thread:                                      │ │
│ │    - Выдать предмет победителю:                              │ │
│ │      player.getInventory().addItem(itemStack)                │ │
│ │    - Отправить победителю сообщение                          │ │
│ │    - Отправить broadcast:                                    │ │
│ │      "§6Аукцион завершён! §eПобедитель: {winner} за {price}"│ │
│ │    - Обновить GUI (если открыт)                              │ │
│ │                                                              │ │
│ │ 5. Обновить таблицу:                                         │ │
│ │    UPDATE auctions SET                                       │ │
│ │      status = 'completed', winner_uuid = ...,                │ │
│ │      completed_at = NOW()                                    │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                        ЗАВЕРШЕНО
                              ↓
    [Предмет выдан победителю]
    [Валюта зарезервирована]
    [Все остальные ставившие → cancelled]
```

## Сценарий 5: Команда `/loveshops buyer <player> <status>`

```
┌─────────────────────────────────────────────────────────────────┐
│ OP выполняет:                                                    │
│ /loveshops buyer steve bad                                       │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ ShopsCommand.onCommand() → handleBuyerStatus()                   │
│ [Async]                                                          │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ 1. Получить UUID игрока:                                    │ │
│ │    playerUUID = Bukkit.getPlayer("steve").getUniqueId()      │ │
│ │                                                              │ │
│ │ 2. Проверить статус:                                         │ │
│ │    if (status not in [default, good, bad, aggressive])       │ │
│ │      return ERROR "Неверный статус"                          │ │
│ │                                                              │ │
│ │ 3. Вставить / обновить в БД:                                 │
│ │    INSERT OR REPLACE INTO buyer_reputation_overrides         │ │
│ │      (player_uuid, status, set_by, set_at, reason)           │ │
│ │    WHERE player_uuid = steve_uuid                            │ │
│ │                                                              │ │
│ │ 4. Back to main thread:                                      │ │
│ │    - Отправить OP сообщение:                                 │ │
│ │      "§a✓ Статус игрока steve изменён на bad"              │ │
│ │    - Логировать в консоль                                   │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              ↓
                        УСПЕШНО
                              ↓
    [Статус сохранён в БД]
    [При следующей попытке продажи проверится этот статус]
    [Если steve уже открыл GUI скупщика, он увидит отказ]
```

## Таблица переходов состояний предмета в buyer_inventory

```
┌─────────────────────────────────────────────────────────────────┐
│ Статус: INCOMING                                                 │
│ - Игрок сдал предмет скупщику                                   │
│ - received_at = NOW()                                            │
│ - sold_at = NULL                                                 │
│ - Хранится до воскресенья 10:00                                  │
└─────────────────────────────────────────────────────────────────┘
                      ↓ (воскресенье 10:00)
┌─────────────────────────────────────────────────────────────────┐
│ Статус: AVAILABLE_IN_SHOP                                        │
│ - Торговец приходит                                              │
│ - Предмет видим в SellerGui                                      │
│ - Можно купить                                                   │
│ - sold_at = NULL                                                 │
└─────────────────────────────────────────────────────────────────┘
              ↓ (игрок кликает)        ↓ (в 18:00)
       SOLD / PURCHASED           DESPAWNED SELLER
              ↓                         ↓
       ┌──────────────┐         ┌────────────────┐
       │sold_at=NOW()│         │ Статус: AWAITING
       │Передан       │         │ NEXT_WEEK
       │покупателю    │         │ Остаются в БД
       │              │         │ Ждут след. вск.
       └──────────────┘         └────────────────┘
                                      ↓ (следующ. вск. 10:00)
                                [Торговец вернулся]
                                [REPEAT цикл]
```
